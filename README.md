# 📊 Análise de Contratos Imobiliários

Projeto de análise exploratória de dados aplicado ao mercado imobiliário.

## 🎯 Objetivo

Analisar uma carteira fictícia de 100 contratos imobiliários para identificar padrões de aluguel, distribuição dos imóveis, receita de administração e indicadores de inadimplência.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub
